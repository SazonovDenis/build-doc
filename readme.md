# build-doc

Сайт документации проекта из Markdown одной командой: страницы, справочники, база данных, общее меню.

Утилита внешняя: скрипты лежат здесь, документация - в проекте.

## Что собирает

Из каталога `doc` проекта (или `--doc`) в `_site` (или `-o`):

| Источник      | Страница                                                                 |
|---------------|--------------------------------------------------------------------------|
| `*.md`        | страница на файл; `readme.md` - `index.html`                             |
| `navigate.md` | не страница, а меню над всеми страницами                                 |
| `dict/*.tsv`  | `dict.html`: таблица на справочник и страницы, которые на него ссылаются |
| `--db DIR`    | `db.html`: описание БД утилитой [doc-db](../doc-db) с общим меню         |

Ссылки `X.md` становятся `X.html`, `dict/X.tsv` - `dict.html#dict-X`, ссылки на каталоги `dict` и `--db` -
`dict.html` и `db.html`. Ссылки внутри документов работают одинаково в `.md` и на сайте.

После сборки проверяются ссылки на `.md`: есть ли файл и якорь.
Битые - `BROKEN ...` пишутся в stderr, код выхода 1.

## Меню - navigate.md

Пример:

```
[Обзор](readme.md)
[ТЗ](tz.md)
---
[Справочники](dict.html)
[База данных](db.html)
---
[Прототип](/app/prototype.html)
```

Строка - пункт меню, `---` - разделитель. Ссылка на `X.md` становится `X.html`, остальные адреса - как есть.

## Как подключить себе

Проект подключает утилиту своими скриптами, например:

```bash
TOOL="${BUILD_DOC:-$ROOT/../build-doc}"
cd "$ROOT"
"$TOOL/build-doc" --db doc/db --func-page tz.functions
```

### Для запуска должно быть установлено

Нужны:

- `pandoc` (проверено на 2.9), Python 3;
- для генерации документации на базу данных `--db` - нужна утилита [doc-db](../doc-db) и то, что нужно ей. По умолчанию
  ищем эту утилиту в каталоге `DOC_DB` рядом с build-doc.
